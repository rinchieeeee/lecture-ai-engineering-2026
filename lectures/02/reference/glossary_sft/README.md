## 条件と採点

- RTX 3090、float32、量子化なし。LoRA r=16、alpha=32、学習率2e-4、20エポック・460ステップ、seed=42。学習時間383.1秒、全学習の平均loss 0.148112、最終ログのloss 0.033868。
- 学習182件、検証62件、評価36問。掲載語12語の直接質問と言い換えを対にし、未掲載語を12語用意した。質問文の重複を避け、未掲載語も学習・検証・評価で分けた。検証データは学習中のloss計算やモデル選択には使っていない。
- 前後でsystem指示、質問、貪欲生成、最大384トークン、思考モード無効、EOS/PADを固定した。評価入力に用語集本文・正解は付けていない。
- 内容は `needs_review` の一致と必須語句で採点し、形式も合格したものを4分類の「正解」とした。未掲載語は一般に実在しても、記載がなく確認が必要と答えるのが正解。

必須語句による簡易自動採点なので、意味が近くても表現が異なると不合格になります。[比較記録](comparison.md) に全問の正解例、目視採点基準、前後の回答原文、判定理由を残しています。学習前の4回答は生成上限に達しました（学習後は0）。掲載語の定義は全て学習データに含まれており、固定36問・seed一つで未知の質問文への対応を比較した結果です。
